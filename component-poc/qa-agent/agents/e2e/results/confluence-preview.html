These checks drive the real UI in an authenticated browser and, for the same data slice, call the real API at https://dev.salesplanning.ingka.com. Each check asserts that the value rendered on screen is the value the API actually returned.

Why this is separate from the other two runs: the Playwright E2E suite mocks every API call, so it proves the UI renders fixture data correctly. The API probes never open the UI, so they prove the API is internally consistent.
