# Severity Matrix

## Critical

Production-blocking failure, data loss risk, or security break. Must fix before merge.

## High

Core functionality broken or significant accessibility/compliance issue. Must fix before merge unless explicitly waived.

## Medium

Behavioral mismatch, regression risk, or non-critical contract issue. Fix in current cycle when possible.

## Low

Minor issue with limited user impact. Track and schedule.

## Info

Observation or optimization suggestion. No immediate action required.
